# Installed local SUN recordings

Six owner-approved Azure Jenny recordings are copied here without changing their bytes. The seventh file, `01-intro.wav`, presents the approved s, short u, and n sequentially with their original pauses. It is an introduction with separate sounds, not a stitched connected blend. Both blend files are intact Azure utterances.

`installed-manifest.json` records exact source files and hashes. Regenerate this installation with `python sound-lab/install-approved-audio.py` from the project root; no network or paid generation is used. Vite bundles these files only when the isolated Sound Lab preview is built. Production build inputs and the homepage remain unchanged.
